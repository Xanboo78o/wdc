# The kit

Every model in this directory is **CC0** from **Kenney** (https://kenney.nl) —
the *Racing Kit*, version 2.0. No attribution required, commercial use fine,
which is what makes it safe to ship on public GitHub Pages. `LICENSE-kenney.txt`
is the licence exactly as it shipped.

These are **files**, not geometry built by code. That is the point of them:

> "NOTHING IS CREATED WITH MATH, ITS ASSETS AND FILES"

A wall is `barrierWall.glb` standing at a position written down in
`data/build/objects.js`. A bridge is `roadStraightBridge.glb`, not a mound of
earth that happens to be the right height. When one is in the wrong place, the
fix is a number in a file you can edit, not a formula you have to re-derive.
